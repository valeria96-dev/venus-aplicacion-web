# Venus · Sitio promocional

Sitio web responsivo y accesible para promocionar Venus, una app de cuidado facial guiado que enseña masajes paso a paso, mide el progreso con fotos y recomienda productos según la piel y el presupuesto.

Tarea 1, Unidad 1 (Diseño y creación de páginas web) de Aplicaciones Web, Universidad Politécnica Salesiana.

**Demostración:** https://valeria96-dev.github.io/venus-aplicacion-web/

## Tecnologías
- HTML5 semántico
- CSS mobile first con variables, Flexbox, Grid y media queries a 768 px y 1024 px
- JavaScript sin librerías: menú adaptable, filtro de masajes y validación accesible

## Cómo verlo localmente
Abrir la carpeta en Visual Studio Code y usar Live Server sobre index.html.
